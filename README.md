# 医询 MedAssist · 症状分析与用药信息参考

一个**医学 + AI** 方向的静态 Web 应用：输入症状描述与病历要点，本地引擎自动匹配可能病因方向并给出 **OTC 用药信息卡 + 非药物建议 + 就医指引**；支持可选接入大模型 API 做 AI 增强分析。

> ⚠️ **本工具不构成医疗建议，不能替代医生诊断与处方。** 用药前请咨询医生或药师；紧急情况请拨打 120。

## 功能

| 模块 | 说明 |
| --- | --- |
| 🔎 分析台 | 快捷症状 chips + 自由文本描述 → 加权匹配引擎输出**至少 3 种关联病症**（直接命中按相关度排序；不足时自动补「相关方向 · 供参考」卡片）→ OTC 药物信息卡 → 非药物建议 → 就医信号 |
| 🚨 红旗拦截 | 胸痛/偏瘫/呼吸困难/呕血/意识改变等急症关键词命中后**暂停常规推荐**，顶部强提示急救行动（120 / 急诊） |
| 💊 用药参考 | 22 张 OTC 药物信息卡（适应证/用法要点/警告/相互作用提示）+ 4 张处方药科普卡（只讲性质，不做推荐） |
| 🕸️ 知识图谱 | 症状—疾病—药物—科室 关联的 canvas 放射图 + 知识库规模统计 |
| 🔌 AI 增强（可选） | 填入自己的 OpenAI 兼容接口（默认智谱 GLM 端点）+ API Key（仅存本机 localStorage），分析时由大模型生成结构化 JSON 并与本地结果合并；失败自动回退本地模式 |

## 安全设计

1. **红旗急症优先**：8 组急症信号关键词（心梗/卒中/气道急症/蛛网膜下腔出血/消化道出血/意识障碍/高热惊厥等）优先于一切推荐流程。
2. **OTC 边界**：推荐区只出现非处方药通用名 + 说明书要点；抗生素、急救药、慢病药只做「为什么必须由医生开具」的科普卡。
3. **三重免责**：全局横幅 + 每个结果卡尾部 + 关于页。
4. **无后端、无追踪**：纯静态离线运行，API Key 仅存本机浏览器 localStorage。

## 运行

双击 `index.html` 即可（纯静态，离线可用）。AI 增强模式需联网与有效 API Key。

## 文件结构

```
medassist/
├── index.html      页面结构
├── css/style.css   样式
└── js/
    ├── data.js     本地医疗知识库（26 病症 / 22 药物卡 / 8 组红旗 / 处方药科普）
    ├── engine.js   加权匹配引擎（症状→病症评分、红旗检测、药物检索）
    ├── kg.js       知识图谱 canvas 可视化
    └── app.js      UI 逻辑 + LLM 增强模式
```

## 架构参考（GitHub 开源项目）

- [liuhuanyong/QASystemOnMedicalKG](https://github.com/liuhuanyong/QASystemOnMedicalKG) —— 基于医疗知识图谱的问答系统（约 4.4 万实体、30 万关系，疾病/症状/药物/检查/科室等 7 类实体，Neo4j 存储 + 意图问答）。本项目借用其「问句解析 → 意图匹配 → 知识查询 → 组装回答」架构，用内置 JSON 知识库 + 加权匹配离线实现，并保留知识图谱可视化。
